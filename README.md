# InputLock

macOS 菜单栏工具：锁定指定的输入法。支持全局锁定，也支持为不同的 App 分别指定输入法。

## 功能

- 枚举系统所有已安装输入法
- 全局锁定：所有应用下强制使用指定输入法
- 按应用锁定：为不同 App 分别指定输入法，App 规则优先于全局规则
- 暂停锁定（5 分钟 / 30 分钟 / 无期限），暂停期间不干扰输入法
- 配置自动保存，重启后保留
- 菜单栏显示当前状态与当前应用
- 不读取、不记录键盘内容

## 构建

需要 Xcode Command Line Tools：

```bash
xcode-select --install
```

构建：

```bash
./build.sh
```

产物：

```text
.build/InputLock.app
```

## 运行

```bash
open .build/InputLock.app
```

或双击 `InputLock.app`。

## 使用

1. 启动后，菜单栏出现键盘图标。
2. 点开菜单，在“全局锁定输入法”中选择要锁定的输入法（如微信输入法）。
3. 如需按应用区分：先切换到目标 App，在菜单中打开“当前应用 的输入法”，选择该 App 要使用的输入法。
4. 需要临时使用其他输入法时，用菜单中的“暂停”功能。

## 常用操作

| 操作 | 方法 |
| --- | --- |
| 全局锁定 | 菜单 → 全局锁定输入法 → 选择输入法 |
| 取消全局锁定 | 菜单 → 取消全局锁定 |
| 为当前 App 指定输入法 | 先切换到 App，菜单 → 当前应用 的输入法 → 选择 |
| 移除当前 App 规则 | 菜单 → 取消 当前应用 的规则 |
| 暂停 5 / 30 分钟 | 菜单 → 暂停 |
| 一直暂停 | 菜单 → 一直暂停 |
| 恢复 | 菜单 → 恢复锁定 |
| 退出 | 菜单 → 退出 InputLock |

## 多台设备使用

- 在 A 机执行 `./build.sh` 生成 `InputLock.app`。
- 拷贝 `InputLock.app` 到其他 Mac（同一 macOS 版本或兼容版本）。
- 首次打开时如提示“无法打开”，在系统设置 → 隐私与安全性 → 仍要打开。
- 本机自用无需开发者证书签名；如要分发给他人，需要 Developer ID 签名与公证。

## 开机自启

系统设置 → 通用 → 登录项 → 登录时打开 → 添加 `InputLock.app`。

## 数据与卸载

- 配置保存在 `~/Library/Preferences/local.inputlock.plist`
- 卸载：退出程序，删除 `InputLock.app` 和上述 plist 文件即可

## 注意

- 需要被锁定的输入法（如微信输入法）必须已加入 macOS 输入法列表。
- 建议在 系统设置 → 键盘 → 文字输入 → 编辑 中关闭“自动切换到文稿的输入法”，避免与按应用记忆互相干扰。
- 密码框、锁屏、安全输入界面、远程桌面等场景，系统可能限制输入法切换。
- 全局锁定期间，在其他 App 中手动切换输入法会被立即拉回。
